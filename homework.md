## 2. What is JavaScript?

JavaScript is a programming language used to make websites interactive and to build web applications.

## 3. What three problems does Git & GitHub solve?

They allow developers to share their code with others and collaborate on projects.
Git tracks changes to code, allowing developers to review their progress and return to previous versions.
GitHub stores repositories online, allowing developers to access their code from different machines and work together.

## 4. What happens when you `fork` a repository?

ou create a copy of someone else's repository in your own GitHub account. You can make changes to your copy without directly affecting the original repository.

## 5. What happens when you clone a repository?

You create a local copy of a repository on your computer so you can work on it using your preferred code editor.

## 6. What is a Pull Request?

A Pull Request is a way to propose changes to a repository and ask for them to be reviewed before they are merged into another branch.
